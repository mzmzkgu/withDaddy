# 아빠랑! (withDaddy)

아이와 함께 가볼만한 장소(키즈카페, 공원, 박물관, 체험 등)를 등록하고 찾아보는 지도 기반 웹앱.

## 구성
- `index.html` — 리스트 / 지도(카카오맵) / My(다녀온 곳) / New(장소 등록) 4개 탭으로 구성된 단일 페이지 앱
- `logo.png`

## 주요 기능
- 지역·유형·타겟(남아/여아)·요금·별점·예약 여부로 장소 필터링 및 검색
- 카카오맵 연동으로 지도에서 장소 확인, 현재 위치 기준 거리순 정렬
- 찜/다녀옴 체크, 로컬 데이터 백업(JSON)/복원
- 새 장소 등록 시 "운영자 검토 후 공식 등록"용 서버 제보 기능 (체크 시에만 서버로 전송, 아니면 기기에만 저장)
- 백엔드: `kgu3405.tplinkdns.com/api/withDaddy` (장소 목록 조회 `/places`, 제보 `/submit`)
